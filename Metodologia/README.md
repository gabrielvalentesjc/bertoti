# Projeto de Desenvolvimento de Sistema de Gestão de Tráfego e Viaturas
Empresa Parceira: IPEM (Regional São José dos Campos)

## Problema:
O controle de abastecimento e deslocamento da frota era realizado de forma manual, utilizando planilhas físicas e digitais. Esse processo era moroso, propenso a erros e causava lentidão no fluxo de dados para o sistema oficial SGI, gerando retrabalho para a equipe técnica e administrativa. Além disso, faltava centralização e agilidade para o monitoramento eficiente do consumo de combustível e da quilometragem dos veículos.

## Solução Entregue pela Equipe:
Desenvolvemos uma aplicação web sob medida para automatizar e digitalizar o controle de abastecimento do IPEM. O sistema permite que os técnicos realizem apontamentos rápidos em tempo real de forma intuitiva, substituindo as antigas planilhas físicas. 

Para os administradores, a solução conta com um dashboard interativo para monitoramento de indicadores de consumo médio e quilometragem, ferramentas de cadastro de viaturas e técnicos, validação de quilometragem para assegurar a integridade dos dados, além da facilidade de exportação de dados mensais para o input no sistema SGI.

Repositório do Projeto: [Atlaz - GitHub](https://github.com/gabrielvalentesjc/Atlaz)

## Tecnologias Utilizadas:
* **Java:** Essencial para o desenvolvimento do back-end robusto e seguro do sistema.
* **Spring Boot:** Facilita a configuração e o desenvolvimento de aplicativos Java, agilizando a implementação de serviços web e RESTful.
* **Vue.js:** Utilizado para desenvolver a interface de usuário dinâmica, reativa e amigável do lado do cliente.
* **Supabase:** Plataforma de banco de dados e backend-as-a-service que simplificou a persistência e gerenciamento dos dados relacionais.
* **Docker:** Utilizado para empacotar e executar aplicações em contêineres, garantindo consistência e portabilidade entre os ambientes.
* **Git e GitHub:** Ferramentas essenciais para controle de versão e colaboração eficiente entre os membros da equipe.
* **Figma:** Utilizado para a prototipagem e design da interface web.
* **IntelliJ IDEA:** Ambiente de desenvolvimento integrado principal.
* **Trello:** Utilizado para a gestão ágil de tarefas e acompanhamento do backlog.
